# 智胜系统外呼取数自动化

## 运行

也可以直接双击图形启动文件：macOS 使用 `start-gui-mac.command`，Windows 使用 `start-gui-windows.bat`。浏览器打开本地控制页面后，填写项目名称和数量并点击“开始任务”，无需在命令行输入参数。任务运行中可点击“结束任务”终止当前自动化任务但保留图形页面和服务窗口，Chrome 浏览器不会被关闭。

### 启动 Chrome 调试模式

先完全退出日常 Chrome，再双击对应文件：

- macOS：`start-chrome-mac.command`
- Windows：`start-chrome-windows.bat`

首次启动后，在打开的 Chrome 中登录系统。然后再运行自动化脚本。

```bash
cd /Users/loydlee/Desktop/Temp/phone-automation
npm start
```

启动后会依次询问项目名称和本次处理数量：项目名称直接回车使用 `其他_调研_服务类调研_服务类调研_1`，处理数量必须是 `0-50` 的整数。脚本每批最多取 20 个，取完一批后自动处理对应的新工单，再继续取下一批。

脚本在点击、弹窗和页面跳转之间会主动等待；取数、打开详情、提交处理失败时最多自动重试 3 次，异常会刷新并回到对应页面。工单列表会跨分页扫描，并确认本批次工单已从待处理列表移除后才会继续取下一批。

如果取数接口返回“进行中的工单数量不能超过20个”，脚本会识别该提示，自动切到工单处理页清理同项目未完成工单，确认清空后再重试取数。

从其他页面切回工单处理页时会强制刷新一次并回到第一页；如果当前已经在工单处理页，则不会重复刷新。
进入工单处理页和空军报表页时，脚本会自动将分页设置为 50 条/页，以减少翻页次数。

每次启动任务后，会先扫描并处理当前列表中该项目已有的全部未处理工单，确认同项目待处理工单清空后才开始取号，避免触发“进行中的工单数量不能超过20个”。

脚本连接你已经登录的 Chrome，不会新建访客窗口，也不会关闭你的 Chrome。首次使用需要完全退出 Chrome，然后用远程调试端口启动：

```bash
/Applications/Google\\ Chrome.app/Contents/MacOS/Google\\ Chrome \\
  --remote-debugging-port=9222 \\
  --user-data-dir="$HOME/chrome-automation-profile"
```

脚本会根据当前页面自动准备目标页：未登录时打开 `https://geek.cdydwx.cn:5000/pc-index/#/login`，门户工作台点击“智胜系统”进入业务系统；如果已经在 `pc-workflow/#/welcome` 或其他业务页，则自动跳转到 `pc-workflow/#/kyxm/usePhone2`。后续继续使用这个 Chrome profile 即可复用登录态。排查失败时，脚本也不会关闭 Chrome。

脚本按项目名称查找可取数项目，读取新工单客户号码，提交“外呼失败”，并把结果写入 `执行结果/外呼取码` 文件夹下按启动时间生成的文件，例如 `外呼号码_20260830_2030.xlsx`：

```text
/Users/loydlee/Desktop/phone-automation/执行结果/外呼取码/外呼号码_启动时间.xlsx
```

Excel 字段为：客户号码、工单编号、项目编号、项目名称、获取时间、处理结果。

### 功能选择

图形页面启动时可选择：

- **外呼取数**：按项目名称取号、处理工单，结果保存到 `执行结果/外呼取码`。
- **空军报表**：输入项目编号，查询二级空军报表，遍历分页并逐条打开“详情”，将详情弹层中的标签和值保存到 `执行结果/空军报表`。
- **工单查询**：输入本次查询数量，从“我处理的”工单列表逐条打开“详情”，导出工单编号、状态、名称、接单时间及详情表单字段到 `执行结果/工单查询`；超过当前页时自动翻页。

空军报表结果文件格式为 `空军报表_年月日_时分.xlsx`。执行前请确保 Chrome 已通过远程调试启动并处于登录状态。

工单查询结果文件格式为 `工单查询_年月日_时分.xlsx`。查询数量为 1-10000 的整数，实际查询条数不会超过列表中的可用工单数。

## 注意

- 每运行一次都会真实消耗一个号码并处理一条工单。
- 不要在系统页面中同时手动取数，否则可能导致工单定位混淆。
- 运行失败时不会写入 Excel，但取数请求可能已经成功，需要先在工单处理中核对后再重试。
